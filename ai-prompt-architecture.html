코드를 쓰는 저장소가 아니라, AI에게 시키는 법을 쌓아두는 저장소

이 저장소는 실제 코드를 담지 않습니다. Claude Code나 Codex 같은 AI 코딩 어시스턴트에게 "무엇을, 어떻게 맡길지"를 스킬·프롬프트 문서로 정리해 쌓아두는 곳입니다. 요청이 들어와서 실제로 다른 저장소에서 쓰이기까지, 5단계로 따라가 보세요.

구조도 — 프롬프트 하나가 쓰이는 길

단계별 자세히

1

🖥️어느 AI 코딩 어시스턴트로 들어와도 방식은 같다

핵심 원칙은 "CLAUDE.md + 지금 필요한 프롬프트 파일 1개만 사용"입니다.

  • Claude Code — CLAUDE.md 자동 인식
  • Codex — 파일을 직접 지정해 함께 전달
2

📜무엇을 담고, 무엇을 담지 않을지부터 정한다

스킬·프롬프트·페르소나 문서만 담고, 행동 규칙·일지·비즈니스 전략은 다른 저장소로 보냅니다.

  • CLAUDE.md — 저장 원칙 + 스킬 추가 규칙(frontmatter, README 2곳 동시 업데이트)
3

🧰상황별로 골라 쓰는 자산 3갈래

상황별 선택 가이드 표 하나로 필요한 파일 1개를 바로 찾습니다.

  • 스킬 114개 — UI/디자인·에이전트조율·창작·음악영상·AI엔지니어링 등 18개 카테고리
  • 가이드 문서 5개 — antigravity_test/docs/ 활용 가이드
  • 루트 공통 지침 — CLAUDE.md, imdaeseong_coding_style.md
4

🚦커밋 전에 3개 문을 통과한다

스킬이 114개로 늘어나도 형식과 링크가 조용히 깨지지 않도록 자동으로 막습니다.

  • validate_skills.ps1 — frontmatter·고유 이름·상호 참조 검사
  • validate_links.ps1 — 로컬 마크다운 링크 존재 여부 검사
  • verify_repo.ps1 + CI — 부작용 가드 회귀 테스트, push·PR마다 강제
5

📦실제로 다른 저장소에서 쓰인다

이 저장소 자체는 결과물을 만들지 않습니다 — 결과물은 스킬을 가져다 쓰는 쪽에서 나옵니다.

  • hermes-agents — 공유 규칙(AGENTS.md)의 원본 제공처
  • ai-workspace — _templates 신규 프로젝트 거버넌스 흐름과 연계
  • 외부 콘텐츠 프로젝트(ai_test·ai_test1 등)가 실제 스킬을 가져다 씀

그래서, 이 저장소로 무엇을 얻나?

코드나 서비스가 아니라 "AI에게 무엇을 어떻게 맡길지"에 대한 재사용 가능한 판단입니다.

✅ 상황별 선택지는 충분18개 카테고리 114개 스킬이 상황별 선택 가이드 표로 정리돼 있어 바로 꺼내 쓸 수 있습니다.
✅ 형식 붕괴는 자동 차단pre-commit 가드 3종이 frontmatter 누락·끊긴 링크·부작용을 커밋 전에 막습니다.
⚠️ 결과물은 프롬프트뿐실제 코드·서비스는 ai_test 계열 외부 저장소에서 만들어집니다 — 이 저장소는 "만드는 법"만 보관합니다.
