# Skill: Copywriting (마케팅 카피라이팅)

전환을 이끌어내는 명확하고 설득력 있는 마케팅 카피를 작성하는 스킬. 설득보다 명확함을 우선한다.

## 작성 전 확인할 것

### 1. 페이지 목적
- 어떤 종류의 페이지인가? (홈페이지, 랜딩페이지, 가격, 기능, 소개)
- 방문자가 취하길 바라는 단 하나의 핵심 행동은 무엇인가?

### 2. 타겟 고객
- 이상적인 고객은 누구인가?
- 그들이 해결하려는 문제는 무엇인가?
- 어떤 반대·주저함이 있는가?
- 그들이 문제를 표현할 때 쓰는 실제 단어는 무엇인가?

### 3. 제품/오퍼
- 무엇을 팔거나 제공하는가?
- 대안과 무엇이 다른가?
- 핵심 변화·결과는 무엇인가?
- 증거(수치, 후기, 사례)가 있는가?

### 4. 맥락
- 트래픽은 어디서 오는가? (광고, 오가닉, 이메일)
- 방문자가 도착 전에 이미 알고 있는 것은 무엇인가?

---

## 카피라이팅 원칙

### 명확함 > 영리함
명확함과 창의성 중 하나를 골라야 한다면 명확함을 고른다.

### 이점 > 기능
기능: 그것이 무엇을 하는가. 이점: 그것이 고객에게 어떤 의미인가.

### 구체성 > 모호함
- 모호함: "워크플로우 시간을 절약하세요"
- 구체적: "주간 리포트 작성을 4시간에서 15분으로 단축"

### 고객의 언어 > 회사의 언어
고객이 실제로 쓰는 단어를 쓴다. 리뷰·인터뷰·고객 문의에서 드러나는 실제 표현을 반영한다.

### 섹션당 하나의 아이디어
각 섹션은 하나의 논지만 전개한다. 페이지 아래로 내려갈수록 논리적으로 이어지게 만든다.

---

## 문체 규칙

1. **단순함 > 복잡함** — "쓰다"가 "활용하다"보다 낫다
2. **구체성 > 모호함** — "혁신적인", "최적화된" 같은 말은 피한다
3. **능동태 > 수동태** — "우리가 리포트를 생성합니다"가 "리포트가 생성됩니다"보다 낫다
4. **자신감 > 유보** — "거의", "매우", "정말" 같은 수식어를 뺀다
5. **보여주기 > 설명하기** — 부사 대신 결과 자체를 묘사한다
6. **정직함 > 자극적임** — 조작된 통계나 후기는 신뢰를 무너뜨리고 법적 위험을 만든다

### 빠른 품질 체크

- 외부인이 헷갈릴 전문 용어가 있는가?
- 한 문장이 너무 많은 걸 하려고 하는가?
- 수동태 구문이 있는가?
- 느낌표가 있는가? (제거한다)
- 실체 없는 마케팅 유행어가 있는가?

## 실전 원칙

**직접적으로 말한다** — 가치를 조건절 속에 파묻지 않는다.
**수사적 질문을 쓴다** — 독자가 자기 상황을 떠올리게 만든다("아마존 반품하기 귀찮으셨죠?").
**비유를 활용한다** — 추상적 개념을 구체적이고 기억하기 쉽게 만든다.
**적절할 때 유머를 섞는다** — 단, 브랜드에 맞고 명확성을 해치지 않을 때만.

## 페이지 구조 프레임워크

### 접히기 전(Above the Fold)

**헤드라인**
- 가장 중요한 메시지 하나
- 핵심 가치 제안을 전달
- 일반적인 것보다 구체적인 것이 낫다

**헤드라인 공식 예시:**
- "{고통 없이} {결과 달성}"
- "{타겟}을 위한 {카테고리}"
- "다시는 {불쾌한 사건}을 겪지 마세요"
- "{핵심 고통을 짚는 질문}"

**서브헤드라인**
- 헤드라인을 보충
- 구체성을 더함
- 1~2문장 이내

**주요 CTA**
- 행동 지향적인 버튼 문구
- 얻는 것을 명확히: "무료로 시작하기" > "가입하기"

### 핵심 섹션

| 섹션 | 목적 |
|---|---|
| 사회적 증거 | 신뢰 구축(로고, 통계, 후기) |
| 문제/고통 | 상황을 이해하고 있음을 보여줌 |
| 해결책/이점 | 결과와 연결(핵심 이점 3~5개) |
| 작동 방식 | 복잡해 보이지 않게(3~4단계) |
| 반대 대응 | FAQ, 비교, 보증 |
| 마지막 CTA | 가치 요약 + CTA 반복 + 리스크 제거 |

## CTA 카피 가이드

**약한 CTA(피할 것):** 제출, 가입하기, 더 알아보기, 여기를 클릭

**강한 CTA(쓸 것):** 무료 체험 시작하기 / [구체적인 것] 받기 / [제품] 실제로 보기 / 첫 [무언가] 만들기 / 가이드 다운로드

**공식:** [행동 동사] + [얻는 것] + [필요시 한정어]

---

## 페이지별 가이드

- **홈페이지**: 여러 타겟을 아우르되 뻔해지지 않게, 가장 폭넓은 가치 제안을 먼저, 방문자 의도별로 명확한 경로 제공
- **랜딩페이지**: 하나의 메시지, 하나의 CTA, 헤드라인을 광고/트래픽 소스와 일치시킴, 한 페이지 안에서 논지를 완결
- **가격 페이지**: "나에게 맞는 게 뭐지?"라는 불안 해소, 추천 플랜을 명확히
- **기능 페이지**: 기능→이점→결과로 연결, 사용 사례 제시
- **소개 페이지**: 왜 존재하는지 이야기, 미션을 고객 이점과 연결, CTA는 여전히 포함

## 톤앤매너

작성 전에 정할 것: 격식 수준(캐주얼/전문적이지만 친근함/공식적), 브랜드 성격(장난스러움/진지함, 대담함/절제됨, 기술적/접근하기 쉬움). 헤드라인은 더 과감하게, 본문은 더 명확하게, CTA는 더 행동 지향적으로.

## 출력 형식

- **페이지 카피**: 섹션별로 정리(헤드라인/서브헤드라인/CTA, 섹션별 본문, 보조 CTA)
- **주석**: 핵심 요소마다 왜 그렇게 썼는지, 어떤 원칙을 적용했는지 설명
- **대안**: 헤드라인·CTA는 2~3개 옵션 + 각 근거
- **메타 콘텐츠**(필요시): 페이지 타이틀(SEO용), 메타 설명
