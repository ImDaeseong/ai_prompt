# Copywriting (마케팅 카피라이팅)

전환을 만드는 카피를 쓰는 스킬. 멋진 문장보다 명확한 문장을 우선한다 — 독자가 두 번 읽어야 이해되는 카피는 그 자체로 실패다.

## 쓰기 전에 답해야 할 질문

**페이지 성격**
- 홈페이지·랜딩·가격·기능·소개 중 무엇인가?
- 이 페이지에서 방문자가 취해야 할 행동 하나는 무엇인가? (두 개 이상이면 페이지를 나눈다)

**독자**
- 누구를 대상으로 쓰는가, 그 사람이 지금 겪는 문제는 무엇인가?
- 결제·가입을 망설이게 만드는 이유는 무엇인가?
- 독자가 본인 문제를 이야기할 때 실제로 쓰는 단어는 무엇인가? (리뷰·문의·인터뷰에서 확인)

**제안**
- 무엇을 파는가, 경쟁 대안과 다른 점은 무엇인가?
- 사용 전/후로 실제 무엇이 달라지는가?
- 그 변화를 뒷받침할 증거(수치·사례·후기)가 있는가?

**유입 맥락**
- 방문자는 어디서 오는가(광고·오가닉·이메일)?
- 페이지에 도착하기 전 이미 알고 있는 정보는 무엇인가?

---

## 카피를 지탱하는 4가지 우선순위

1. **명확함이 창의성을 이긴다.** 재치 있는 카피와 즉시 이해되는 카피 중 하나만 고를 수 있다면 후자를 고른다.
2. **이점이 기능을 이긴다.** 기능은 "무엇을 하는가"고, 이점은 "그래서 나한테 뭐가 좋은가"다. 카피는 항상 후자로 끝나야 한다.
3. **숫자가 형용사를 이긴다.** "시간을 아껴드립니다"는 누구나 쓸 수 있는 말이다. "매주 쓰던 보고서 작성 4시간을 15분으로 줄입니다"는 검증 가능한 주장이다.
4. **고객의 말이 회사의 말을 이긴다.** 사내 용어·업계 전문 표현 대신 고객이 실제 검색하고 실제 말하는 표현을 쓴다.

섹션 하나에는 논지 하나만 담는다. 페이지를 위에서 아래로 읽었을 때 다음 섹션이 이전 섹션의 질문에 답하는 순서가 되어야 한다.

---

## 문장 단위 체크리스트

써 놓은 카피를 다음 기준으로 다시 읽는다.

- 이 산업을 모르는 사람이 걸릴 만한 용어가 있는가 → 있으면 풀어 쓴다
- 한 문장이 두 가지 주장을 동시에 하고 있는가 → 나눈다
- 수동태로 쓰인 곳이 있는가 → "우리가 ~합니다" 형태로 바꾼다
- "거의", "매우", "정말" 같은 확신 없는 수식어가 있는가 → 뺀다
- 느낌표가 있는가 → 뺀다
- 근거 없이 "혁신적인", "최적화된" 같은 말만 앞세운 곳이 있는가 → 구체적 사실로 바꾸거나 지운다

## 실전에서 먹히는 장치

- **에두르지 않는다** — 조건절 뒤에 진짜 메시지를 숨기지 않는다.
- **질문으로 시작한다** — 독자가 자기 얘기라고 느끼게 만든다 ("반품하려고 30분 동안 헤매신 적 있으신가요?").
- **비유로 추상을 구체로 바꾼다** — 개념을 설명하기보다 그림이 그려지게 한다.
- **어울릴 때만 유머를 쓴다** — 브랜드 톤에 안 맞거나 메시지를 흐린다면 뺀다.

## 페이지 상단(첫 화면) 구조

**헤드라인**
가장 중요한 메시지 하나만 담는다. 뭉뚱그린 표현보다 구체적인 결과가 낫다.

자주 쓰는 형태:
- "{고통 없이} {결과를 얻는다}"
- "{타겟 고객}을 위한 {카테고리}"
- "다시는 {불쾌한 경험}을 겪지 않는다"
- "{독자의 핵심 고민을 짚는 질문}"

**서브헤드라인**: 헤드라인이 못 담은 구체성을 1~2문장으로 보충한다.

**1차 CTA**: 버튼을 누르면 무엇을 얻는지 동사로 명시한다 — "가입하기"보다 "무료로 시작하기".

## 본문 섹션 구성

| 섹션 | 역할 |
|---|---|
| 사회적 증거 | 로고·수치·후기로 신뢰를 만든다 |
| 문제 정의 | 독자의 상황을 이해하고 있음을 보여준다 |
| 해결책과 이점 | 핵심 이점 3~5개를 결과와 직접 연결한다 |
| 작동 방식 | 3~4단계로 단순하게 보이게 한다 |
| 반대 의견 대응 | FAQ·경쟁 비교·보증으로 남은 의심을 없앤다 |
| 마지막 CTA | 가치를 다시 요약하고, 리스크를 제거하고, CTA를 반복한다 |

## CTA 문구 만드는 법

**피할 표현**: 제출, 가입하기, 더 알아보기, 여기를 클릭 — 아무 정보도 안 준다.

**쓸 표현**: 무료로 시작하기 / [구체적인 것] 받기 / 지금 확인하기 / 가이드 다운로드 — 클릭 후 무엇이 오는지 안다.

공식: [행동 동사] + [얻는 것] + [필요하면 조건 하나]

## 페이지 유형별 방향

- **홈페이지**: 여러 타겟을 아우르되 애매해지지 않게, 가장 넓은 가치 제안을 먼저, 방문 의도별 경로를 따로 제공
- **랜딩페이지**: 메시지 하나·CTA 하나, 헤드라인을 유입 광고 문구와 맞춤, 페이지 안에서 논지를 끝맺음
- **가격 페이지**: "어떤 플랜이 나한테 맞는가"라는 불안부터 해소, 추천 플랜을 시각적으로 표시
- **기능 페이지**: 기능 → 이점 → 실제 결과 순서로 연결, 사용 사례를 함께 제시
- **소개 페이지**: 왜 이 일을 하는지 이야기하고 미션을 고객 이점과 연결, CTA는 여전히 남긴다

## 톤 정하기

작성 전에 확정: 격식 수준(캐주얼/전문적이지만 친근함/공식적), 브랜드 성격(장난스러움 vs 진지함, 대담함 vs 절제됨). 헤드라인은 과감하게, 본문은 명확하게, CTA는 행동 지향적으로 — 세 요소의 톤이 서로 어긋나지 않게 맞춘다.

## 결과물 형식

- **페이지 카피**: 섹션별로 정리(헤드라인/서브헤드라인/CTA, 섹션 본문, 보조 CTA)
- **선택 이유**: 핵심 문구마다 어떤 원칙을 적용했는지 한 줄로 남긴다
- **대안**: 헤드라인·CTA는 2~3개 옵션과 각각의 근거를 함께 제시
- **메타 콘텐츠**(필요시): SEO용 페이지 타이틀, 메타 설명
